What Came Before?

Before the existence of DNS, the internet used to use a file called HOSTS.TXT to match specific computer names with their IP addresses. However, as the internet kept growing and growing, keeping this file constantly updated became incredibly difficult. In short, the internet outgrew this simple system.

The Creation of DNS

In 1983, a computer scientist named Paul Mockapetris created the Domain Name System (DNS) to try and fix this problem. DNS allowed computers to find each other using domain names instead of needing the numerical IP addresses from before. It also fixed the problem of rapid growth that was previously existent in the last system. With this new system, the internet could grow larger and larger without being held back.

How It Affects Today

DNS is a major part of how the world wide web operates. Whenever someone types in the name of the website they’re trying to visit, DNS helps top locate the IP address so that the browser can connect to it. Also, as time has gone on, DNS has only improved performance and security. With this system in place, the internet is free to explore for anyone.

What Happens When You Type a URL

Let's say you're trying to go to the website google.com, you just type it into the search bar and... BOOM you're done, right? While it may look like that to you, there is so much that happens within those few seconds of loading that your computer does. Firstly, your browser needs the IP address to connect to the server that is hosting the website. Remember, an IP address is just the numerical address that identifies a device or server on a network. If you have recently looked up the website, then your system already has the answer stored and will give the IP address to your computer. However, if you don't, then there is a long process that must happen.

Step 1

First, your computer contacts a Recursive DNS Server, which is your computer’s main DNS server that it contacts when it needs help. Your computer sends something called a DNS Query where it requests to find information about a domain name.

Step 2

Next, your Recursive DNS Server will contact a Root DNS Server, which are servers that know where specific domains like .com or .org are managed. The root server then provides the IP address for the authoritative server that is in charge. These servers are known as the Top-Level Domain Servers (TLD Servers). .

Step 3

After that, the TLD Server then provides the IP address for the server in charge of managing your second-level domain (SLD), for example the “google” part in google.com. This SLD Server is the one that actually has the IP address for the website you’re trying to go to.

Step 4

Finally, the SLD Server gives your computer the IP address to the website, which is then passed to your browser. Only then can you actually get to the website.

Conclusion

As you can see, the journey to getting to a website is long and a lot more complex than it seems. Now you know what happens when you type a URL into your browser and the path to obtaining an IP address.
